# AI Sentiment Analysis System

## Description
This project analyzes social media posts and classifies sentiment as Positive, Negative, or Neutral.

## Technologies Used
- Python
- Streamlit
- TextBlob

## Features
- Sentiment Analysis
- Positive/Negative/Neutral Classification
- Interactive Web Interface

## How to Run

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.py
