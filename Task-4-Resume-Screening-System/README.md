# AI Resume Screening System

## Description
An AI-powered system that screens resumes and ranks candidates based on required skills.

## Technologies Used
- Python
- Streamlit
- PyMuPDF
- Pandas
- Scikit-Learn

## Features
- Upload resume PDFs
- Extract text automatically
- Match resumes with required skills
- Candidate ranking system
- Best candidate recommendation

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
